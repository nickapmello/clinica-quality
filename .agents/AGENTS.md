# Project Rules - Quality Clínica do Movimento

- **Automatic Git Push to Vercel**: Whenever code files in this repository are created, modified, or updated, automatically stage (`git add .`), commit with a descriptive message (`git commit -m "..."`), and push (`git push origin main`) to `main` so that Vercel (`https://clinica-quality.vercel.app/`) deploys the changes immediately.
- **Visualização Imediata**: Sempre fornecer um link de visualização rápida de 1 clique após qualquer alteração.
